Transpiles to C

rin compiler

A small systems language that compiles to readable C, so it runs wherever C runs and links against anything C links against. Explicit sizes, declarations that read left to right, generics resolved while compiling, and reflection the compiler emits for you.

Quickstart

Install it, then build something

Install

Point RIN_HOME at the packaged folder, or put it on PATH. std must sit beside rin.exe; the compiler refuses to start without it.

setx RIN_HOME C:\devel\rin-windows-x64
rin --version

Package output

The build copies the compiler and src\std into a folder that can live on PATH.

C:\devel\rin-windows-x64\
    rin.exe
    rinbind.exe
    std\

Compile one file

The compiler finds the sibling std folder automatically.

rin compile src\main.rin -o build\rin_gen\main.c --header build\rin_gen\main.h

Check only

Used by editor tooling and diagnostics without producing build artifacts.

rin check src\main.rin --diagnostics=json

Build a whole project

Describe the build once in a build.rin — ordinary rin globals, parsed by the same front end — and the compiler drives cmake and the generator.

build_name:  *const char = "hello";
build_entry: *const char = "src/main.rin";

rin build

Shape

Small syntax, explicit output

The language stays close to C. The compiler owns the type system, generics, reflection, diagnostics, and C emission.

Declaration-first syntax

name: type is used for locals, globals, fields, structs, enums, aliases, and procedures.

Native monomorphization

Array<payload> and sum<payload> emit concrete C structs and procs.

Typed operations

Generic algorithms can call typed implementations such as add<T> and resolve per concrete type.

Automatic reflection

Payload<> lowers to immutable metadata for field names, offsets, sizes, enum values, and type facts.

Compiler-driven formatting

printfmt("{}" resolves argument types and lowers to concrete print<T> calls.

C interop remains direct

cinclude, external, and external_emit keep C APIs visible without wrapping everything.

Line mapped generated C

Generated C uses #line so native compiler errors and debugger stepping can point back to the .rin source.

Exhaustive switches

A switch over an enum that lists cases and writes no default must handle every member. Writing default opts out, so a large enum costs nothing.

Three C compilers

The generated C is checked against clang, clang-cl and MSVC cl, with the same expected output from each.

Editor path

The LSP shell calls rin check --diagnostics=json and publishes compiler-owned diagnostics.

Syntax

Current language examples

Basics

Unified forms

  • value: T = expr;
  • Name: struct = { field: T; }
  • name: proc(args)->T = { ... }
  • Generic: struct<T> = { ... }

Metaprogramming

  • Payload<>.count, .size, .variant.fields[i]
  • Array<T> native generic types
  • print: proc<Payload>(...) typed operation specialization
  • printfmt("{}\n", value) compiler lowered formatting

Interop

  • cinclude "stdio.h"
  • #define FLAG passes through to C
  • proc[callconv(NAME)](...)
  • external and external_emit

Compiler

One merged generated unit

Imports are resolved by the compiler, then emitted as C in a deterministic order.

Default project compile

rin compile src\main.rin -o build\rin_gen\main.c

If no header path is given, the compiler can derive the companion header path from the C output path.

Generated files

build\rin_gen\
    main.c
    main.h
    Array_payload.h
    Array_payload.c

Generated native monomorph headers stay build-local. Authored code remains .rin.

Diagnostics

rin check src\main.rin --diagnostics=json --stdin-path src\main.rin

The compiler is the source of truth for errors; the LSP should stay a thin transport layer.

Standard Library

Small runtime, arena-shaped

Containers

Array.rin, Vec.rin, Node.rin, List.rin, Map.rin, Option.rin, and Result.rin are written in rin, not bound from C.

No C string library

cstr.rin and fmt.rin replace string.h and snprintf in rin. The 25,000-line engine built on this uses none of them.

Views

slice<T> is the borrowed half of Array<T>: a pointer and a length, owning nothing, free to sub-slice.

Strings and paths

string8 owns arena memory, string8slice borrows, and path helpers normalize slash handling at the rin level.

Printing

Print.rin provides concrete printers; printfmt uses compiler type information to pick the right printer.

Debug

  2. 2

  3. 3

  4. 4
